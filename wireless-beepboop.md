# beep_boop(Wireless):
    >Basically, it is a wireless ctf challenge.
    >I had a raw radio frequency file 'beepboop.iq' and a hint is that a signal was transmitted at **500 kHz**. The task is to  decode the signal and retrieve the flag.
    >I downloaded and inspected a file.
    >I analyzed the signal with  Inspectrum and by that I came to know signal was Morse code
    >I decoded it using morse decoder and got the flag
    
## TOOLS USED:
    >wget,file
    >inspectrum
    >morse decoder
